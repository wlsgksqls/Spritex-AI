# Spritex AI

스프라이트 시트 AI 생성 서비스

Spritex AI는 사용자가 스프라이트 시트 규격을 정하고, 프롬프트와 참고 캐릭터로 원하는 캐릭터의 모습·모션을 요청하면 게임용 스프라이트 시트를 만들어 주는 웹 서비스입니다.

## 무엇을 해결하는가

픽셀 아트 / 게임 스프라이트 제작은 보통 이렇게 어렵습니다.

- 캐릭터 디자인을 먼저 잡고
- 방향(앞/뒤/좌/우)마다 같은 캐릭터로 맞춰 그리고
- 걷기, 공격, 피격 같은 모션을 프레임 단위로 그리고
- 시트 크기, FPS, 루프 방식까지 엔진에 맞게 맞춰야 합니다.

Spritex AI는 이 과정을 **규격 지정 → 캐릭터 기본 모습 확정 → 모션 시트 생성**의 흐름으로 줄입니다. 결과물은 미리보기로 바로 확인하고, 스프라이트 시트 이미지와 GIF로 내려받을 수 있습니다.

## 핵심 사용 흐름

의도한 제작 순서는 아래와 같습니다.

### 1. 스프라이트 크기 지정

`16x16` / `32x32` / `64x64` 중에서 한 칸(프레임) 크기를 먼저 정합니다. 이후 생성되는 기본 모습과 모션 시트는 이 크기를 기준으로 맞춰집니다.

### 2. 캐릭터 기본 모습 제작 (360도 4장)

캐릭터의 정체성을 먼저 고정합니다. 앞 / 뒤 / 왼쪽 / 오른쪽, 네 방향 기본 포즈를 만들어 참고 캐릭터로 사용합니다. 이 단계가 있어야 이후 모션이 같은 캐릭터처럼 유지됩니다.

### 3. 스프라이트 생성기에 참고 캐릭터 투입

확정한 4방향 기본 모습을 참고 캐릭터로 넣고, 어떤 모션의 시트를 만들지 프롬프트로 요청합니다.

예: `빨간 망토 전사가 검을 휘두르는 공격 모션, 사이드 뷰, 8프레임`

### 4. 미리보기

생성이 끝나면 옆 패널에서 모션을 재생해 봅니다. 프레임이 자연스럽게 이어지는지, Inplace 설정이 맞는지, 루프가 의도대로인지 확인합니다.

### 5. 다운로드

마음에 들면 스프라이트 시트(이미지)와 GIF를 내려받습니다.

## 사용자가 조작하는 옵션

### 스프라이트 크기

한 프레임의 픽셀 크기입니다. 크기는 가장 먼저 정합니다. 기본 모습 4장과 이후 모션 시트가 모두 이 그리드에 맞춰지기 때문입니다.

| 크기 | 용도 |
| --- | --- |
| 16x16 | 작은 캐릭터, 타일 게임, 레트로 도트 |
| 32x32 | 일반적인 2D 캐릭터 기본값 |
| 64x64 | 디테일이 필요한 주인공 / 보스급 |

### 프레임 수 & FPS

- **프레임 수:** 한 모션을 몇 장으로 나눌지입니다. 많을수록 움직임이 부드럽고, 시트는 가로로 길어집니다.
- **FPS:** 미리보기와 GIF가 초당 몇 장으로 재생될지입니다. 시트 자체는 프레임 이미지의 나열이고, FPS는 재생 속도입니다.

예시:

- 걷기 8프레임 / 8 FPS → 느긋한 걸음
- 공격 6프레임 / 12 FPS → 짧고 빠른 타격

### Inplace On / Off

캐릭터가 시트 안에서 어떻게 이동하는지를 정합니다.

- **On (제자리 고정):** 캐릭터의 발/중심이 프레임마다 같은 자리에 있습니다. 엔진에서 캐릭터 좌표를 직접 옮기는 방식(대부분의 플랫폼 게임 걷기/점프)에 맞습니다. 시트를 그대로 재생해도 제자리에서 팔다리만 움직입니다.
- **Off (상하좌우 오프셋 허용):** 모션 자체에 이동이 들어갑니다. 돌진, 구르기, 점프 궤적처럼 캐릭터가 프레임 안에서 실제로 위치가 바뀌는 연출에 씁니다.

### 시점

카메라가 캐릭터를 보는 각도입니다. 기본 모습 4장과 모션이 같은 시점을 써야 시트가 게임에 바로 들어갑니다.

- **사이드 뷰:** 옆에서 본 2D 플랫포머 / 횡스크롤
- **탑 뷰:** 위에서 내려다본 탑다운 RPG / 전략
- **쿼터뷰:** 비스듬히 내려다본 쿼터뷰 / 아이소메트릭에 가까운 연출

### 루프

모션이 끝났을 때 어떻게 이어질지입니다.

- **Looping (무한 반복):** 마지막 프레임 다음이 다시 첫 프레임입니다. 걷기, 달리기, 대기(idle), 비행처럼 계속 반복되는 상태에 씁니다.
- **One-shot (한 번 재생 후 idle 복귀):** 모션을 한 번만 재생하고, 끝나면 기본 대기 포즈로 돌아가야 합니다. 공격, 피격, 점프 착지, 스킬 시전처럼 "동작이 끝나는" 모션에 씁니다.

미리보기와 GIF는 이 설정에 맞춰 재생됩니다. Looping은 계속 돌고, One-shot은 한 번 보여주고 idle로 멈춥니다.

### 프롬프트

만들고 싶은 캐릭터와 모션을 글로 적습니다.

포함하면 좋은 내용:

- 누구인지 (종족, 직업, 분위기)
- 무엇을 하는지 (걷기, 베기, 피격, 캐스팅)
- 어떤 느낌인지 (묵직한 대검, 가벼운 도적, 귀여운 슬라임)

이미 위에서 고른 옵션과 겹치지 않게, 옵션으로 정한 크기/시점/루프는 컨트롤에서 맞추고 프롬프트에는 연출을 적습니다.

### 참고 캐릭터

캐릭터의 생김새를 고정하는 입력입니다.

권장 흐름에서는 2단계에서 만든 360도 4장(앞/뒤/좌/우)을 여기에 넣습니다. 생성기는 이 참고 이미지를 기준으로 색, 실루엣, 장비, 머리 스타일을 유지한 채 요청한 모션 시트를 만듭니다.

같은 참고 캐릭터로 걷기·공격·피격을 따로 만들면, 한 게임 캐릭터의 모션 세트가 됩니다.

## 화면에서 일어나는 일 (미리보기 & 결과)

생성 결과는 두 갈래로 보여 줍니다.

- **왼쪽(또는 본문): 완성된 스프라이트 시트**  
  프레임이 한 줄(또는 그리드)로 붙은 이미지입니다. 게임 엔진에 넣을 실제 에셋입니다.
- **옆 패널: 모션 미리보기**  
  시트를 잘라 FPS에 맞춰 재생합니다. Inplace / 루프 설정이 눈에 보이는 곳입니다. 여기서 어색하면 옵션이나 프롬프트를 바꿔 다시 생성합니다.

다운로드:

- **스프라이트 시트 이미지:** PNG 등, 프레임이 붙은 시트. 엔진 스프라이트 리소스로 사용.
- **GIF:** 미리보기와 같은 재생. 공유, 기획 문서, 포트폴리오용.

## 왜 "기본 모습 4장"을 먼저 만드는가

모션만 바로 요청하면 프레임마다 얼굴, 옷 색, 무기 모양이 조금씩 달라지기 쉽습니다. 게임 스프라이트는 같은 캐릭터가 방향만 바뀌고 동작만 바뀌어야 합니다.

그래서 Spritex AI는 순서를 나눕니다.

1. 크기(그리드)를 고정하고
2. 네 방향 기본 포즈로 "이 캐릭터는 이런 모습이다"를 확정한 뒤
3. 그 모습을 참고로 모션 시트를 뽑습니다.

360도 4장은 사이드/탑/쿼터 시점에 맞춰 앞·뒤·좌·우를 의미합니다. 이후 걷기 시트, 공격 시트도 이 네 방향 비율을 따라가게 하는 것이 목표입니다.

## 어떤 사람에게 맞는가

- **인디 게임 개발자:** 프로토타입용 캐릭터 시트를 빨리 뽑아 엔진에 넣고 싶을 때
- **픽셀 아트 입문자:** 프레임 수, FPS, 루프, Inplace 같은 시트 규칙을 옵션으로 배우면서 결과물을 보고 싶을 때
- **기획자 / 팀:** 전투 모션 아이디어를 GIF로 공유하고 싶을 때

완성 상업 아트를 대체한다기보다, "규격에 맞는 캐릭터 모션 시트"를 빠르게 얻는 도구로 씁니다.

## 용어 정리

| 용어 | 의미 |
| --- | --- |
| 스프라이트 | 게임 화면에 올리는 2D 이미지 조각. 보통 한 캐릭터의 한 순간 모습. |
| 스프라이트 시트 | 그 조각들을 한 장에 이어 붙인 이미지. 엔진이 칸을 잘라 애니메이션으로 재생합니다. |
| 프레임 | 시트의 한 칸. 한 장의 포즈입니다. |
| Idle | 아무 행동도 하지 않을 때의 기본 대기 포즈. One-shot 모션은 끝난 뒤 여기로 돌아갑니다. |
| Inplace | 모션 재생 중 캐릭터가 시트 칸 안에서 제자리에 있는지 여부. |

## 현재 상태

이 문서는 서비스 기획을 정리한 소개입니다. 구현(웹 UI, 생성 파이프라인, 미리보기 플레이어, 다운로드)은 이후 단계에서 이 흐름을 기준으로 붙입니다.
